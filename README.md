# 🌟 English for Beginners

### English–Telugu Vocabulary Learning & Analytics Platform

An interactive English vocabulary learning and analytics application developed using **Python, Natural Language Processing (NLP), Statistics, and Streamlit**.

The project is designed to help beginners improve their English vocabulary, understand word meanings in Telugu, practice sentence formation, and explore language patterns through interactive data visualizations and statistical analysis.

## 🎯 Project Objectives

- Develop an interactive English–Telugu vocabulary learning platform.
- Help beginners understand English words with Telugu meanings and example sentences.
- Improve vocabulary knowledge through synonyms, antonyms, and grammatical word forms.
- Apply Natural Language Processing techniques to analyze English sentences.
- Perform statistical analysis on vocabulary and sentence structures.
- Visualize vocabulary patterns using interactive graphs.
- Provide vocabulary quizzes and practice activities for learners.

## 📚 Dataset Description

The project uses a curated dataset containing **594 English vocabulary entries**, including everyday conversational words, expressions, and descriptive vocabulary.

The dataset contains:

- English vocabulary words
- English meanings and Telugu translations
- Synonyms and antonyms
- Parts of speech
- Base verb forms
- Noun, adjective, and adverb forms
- Original English example sentences
- Telugu translations of example sentences

The dataset is used for vocabulary exploration, Python data analysis, statistical analysis, and NLP-based sentence processing.

## 🚀 Project Features

- Search English vocabulary words.
- View English and Telugu meanings.

- Identify grammatical word forms.
- Learn through English sentences and their Telugu translations.

### 📊 2. Python Data Analytics

Analyze the vocabulary dataset using Python and Pandas.

- Data loading and preprocessing
- Missing-value identification
- Duplicate-word detection
- Parts-of-speech distribution
- A–Z vocabulary frequency analysis
- Word-length distribution
- Sentence-length analysis

### 📈 3. Statistical Analysis

Apply descriptive and exploratory inferential statistical techniques to understand vocabulary characteristics.

**Descriptive Statistics**
- Mean
- Median
- Standard deviation
- Minimum and maximum values
- Frequency distributions

**Inferential Statistics**
- Confidence intervals
- Exploratory one-way ANOVA
- Statistical comparisons across parts-of-speech categories

### 🧠 4. Natural Language Processing (NLP)

The NLP module uses **spaCy** to analyze English sentences.

- **Tokenization:** Splitting sentences into individual tokens.
- **Lemmatization:** Identifying the base forms of words.
- **Part-of-Speech Tagging:** Classifying nouns, verbs, adjectives, and adverbs.
- **Stop-Word Identification:** Recognizing commonly occurring functional words.
- **Named Entity Recognition:** Identifying entities such as people, places, and organizations.

The NLP Sentence Analyzer allows users to enter their own English sentences and view the predicted linguistic structure.

The dashboard includes:

- Statistical distribution visualizations

## 📊 Project Workflow

1. **Data Collection:** Prepare the English–Telugu vocabulary dataset.
2. **Data Preprocessing:** Check missing values, duplicates, and data consistency.
3. **Exploratory Data Analysis:** Examine vocabulary patterns and grammatical categories.
4. **Statistical Analysis:** Calculate descriptive statistics, confidence intervals, and exploratory ANOVA.
5. **NLP Processing:** Analyze English sentences using spaCy.
6. **Data Visualization:** Develop interactive graphs using Plotly.
7. **Dashboard Development:** Integrate vocabulary learning, statistics, NLP, and quizzes using Streamlit.
